GitHub issue triage, suggested

Sort every
issue fast.first.

The Issue Triage Assistant reads the title and description of a GitHub issue and suggests one label: bug, feature or question. It shows how sure it is and marks the unsure ones for a person to check. It only suggests. A person decides.

Start How it works

From issues to a label.

01

Collect

Labelled issues come from the NLBSE 2024 data: five open source projects, 500 issues per label in the training and the test file.

02

Compare

A sentence model is fine-tuned with SetFit. Simpler models are trained beside it so its score means something.

03

Choose

The model with the best score on a development slice is kept. The test file is scored once, at the end.

04

Suggest

Paste one issue or upload a CSV. You get a label, a confidence and a review flag. A person decides.

What this does not show

The test file uses the same five projects as the training file, so these numbers say nothing about a project the model has never seen.

The model is below the competition's own template. It is one pooled classifier with a smaller encoder, fitted on 1,196 issues.

Labels come from each project's own labelling and contain noise. The review threshold leaves about two thirds of issues without a review flag.
